# cli-helper-51

cli-helper-51 is a versatile command-line interface (CLI) tool designed to simplify common development tasks. Built in Python, it enhances productivity by providing easy-to-use commands for monitoring system performance and managing project workflows.

## Features

- **System Monitoring**: Get real-time statistics of CPU, memory, and disk usage with a single command.
- **Task Automation**: Create, schedule, and manage repetitive tasks efficiently using intuitive commands.
- **Environment Setup**: Effortlessly set up and configure virtual environments for Python projects with just one command.
- **Custom Commands**: Extend functionality by creating custom commands that fit your specific workflow needs.

## Installation

To install cli-helper-51, ensure you have Python 3.x and pip installed on your system. Then run the following:

```bash
pip install cli-helper-51
```

## Basic Usage Example

After installation, you can start using cli-helper-51 right away. Here’s a quick example of checking your system's performance:

```bash
cli-helper monitor
```

This command will provide a snapshot of your CPU, memory, and disk usage.

For task automation, you can create a new task by using:

```bash
cli-helper task create "Daily Backup" --time "2:00 AM"
```

This command sets up a new task that automatically backs up your files every day at 2:00 AM.
